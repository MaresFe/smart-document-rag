# Smart Document RAG Frontend

React, TypeScript ve Vite tabanlı kullanıcı arayüzüdür. Self-hosted kurulum için depo kökündeki `README.md` dosyasını kullan.

Yerel frontend geliştirme komutları:

```bash
cp .env.example .env
npm ci
npm run dev
```

Kalite kontrolleri:

```bash
npm run test:coverage
npm run lint
npm run build
npm audit --audit-level=high
```
